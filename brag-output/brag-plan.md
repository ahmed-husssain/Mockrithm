# Brag Plan: Mockrithm

## What is this app?
Mockrithm is an enterprise-grade AI technical mock interview platform combining real-time speech telemetry (WPM, filler words, STAR scoring), live multi-language coding execution, and ATS resume optimization into a private, focused sandbox.

## The angle
Quiet mastery. In an industry full of noisy resume tips and stressful interview guesswork, Mockrithm provides the sharpest engineering playground: real-time AI telemetry that listens, measures, grades, and prepares developers to walk into top-tier technical interviews with absolute confidence.

## Hook (first 2-3 seconds)
Cosmic dark backdrop with an electric radial pulse. A minimal audio waveform comes alive as a razor-sharp headline reveals:
*"Top tech interviews aren't won on luck."*
*"They're mastered in the sandbox."*

## Key moments (the middle)
- **Scene 2 — The Conversational AI Engine**: Real-time voice telemetry with a 32-bar reactive waveform tracking speech pace (135 WPM), vocal filler detection (0 "um"s logged), and live STAR method adherence.
- **Scene 3 — Dynamic Code & System Design**: Live syntax execution in 40+ languages, automated test cases, and algorithmic complexity scoring ($O(N)$ runtime verified).
- **Scene 4 — The Readiness Scorecard**: Instant session telemetry report card. Overall readiness mark surges to **96%**, unlocking the FAANG-ready achievement badge.

## Outro / punchline
The screen clears to the refined brand signature:
*"Where talent rises through the practice."*
**Mockrithm**
*Begin Journey → mockrithm.com*

## User flow worth showing
Entry (Select FAANG Behavioral or System Design track) → Key Action (Speak with live AI voice interviewer, execute Python/TypeScript code) → Result (Detailed STAR feedback breakdown, WPM telemetry, and ATS-optimized score).
